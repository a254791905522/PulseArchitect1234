How to Play

No tutorial dump. Read the board, then tap. One wrong pulse costs a life.

01 / SOURCE

Tap a blue node

Release an energy pulse along the connected traces. Every live path lights as the charge travels.

02 / SEQUENCE

Wake machines A, B, C

The top tracker names the next unit. Activate intermediate machines in that exact order before the core will accept power.

03 / BRANCH

Split one pulse

Later boards fork. A single tap can energize several machines at once — or waste a life if the order is wrong.

04 / TIMING

Choreograph timed paths

Some traces only stay open for a beat. Open the timed lane, then send the pulse before it goes dark.

About Pulse Architect

Pulse Architect is a circuit-logic game: you are the operator who keeps a dark energy grid online. Blue sources emit the pulse. Gray machines must wake in a prescribed order. The green reactor is the only finish that counts.

Early boards teach a straight line from source to core. Mid-game adds forks, unused traces, and labeled machines. Later stages mix timing windows with multi-source layouts so you have to read the whole schematic before you tap.

The objective never changes — deliver power cleanly — but the architecture does. If you like quiet concentration, neon spaces, and puzzles that punish haste, this grid is built for you.
